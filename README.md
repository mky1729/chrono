# Chrono — 宇宙の始まりから、時間の果てまで。

宇宙誕生、地球史、生命進化、世界史、日本史、そして宇宙の未来を、一つの横向き年表で探索する Web アプリです。

## 主な機能

- カーソル位置を基準にしたホイールズームと、タッチ端末のピンチズーム
- ドラッグで時代を移動、ズーム倍率に応じて出来事を自動表示
- 宇宙・地球・生命・人類・日本史・未来のレーンの表示切り替え
- 出来事の検索、年代へのジャンプ、詳細パネル
- 実際の年代を保持しながら、膨大な時間を見渡す非線形の時間座標
- 過去の出来事と未来の予測を明示的に区別
- 出来事と時代のデータは src/data.ts に集約

## 開発

Node.js 20.19 以降、または 22.12 以降を推奨。

    npm install
    npm run dev

    npm run build
    npm run preview

GitHub Pages で公開する場合、リポジトリ Settings > Pages > Build and deployment の Source を **GitHub Actions** に設定してください。`main` ブランチへの push で .github/workflows/deploy.yml がビルドとデプロイを行います。Vite の base は `/chrono/` に設定済みです。

## 出来事を増やす方法

`src/data.ts` の `moments` と `eras` に追加するだけです。出来事の `year` は西暦を数値で表現します。大きな負数は数十億年前、未来の大きな正数は理論的予測を表します。日本史などの紀元前は天文学的紀年法（紀元前1年 = 0）で扱います。紀元前表記の詳細を表示するときは変換して出力します。

未来の出来事には `kind: 'forecast'` を指定してください。年代は概数であり、新しい研究によって変わる場合があります。

## 設計メモ

時間の座標は、現在付近の分解能を保ちながら遠い過去・未来を圧縮する非線形スケールです。**画面上の横幅は経過年数に比例しません**。左下の注意書きにも示しています。宇宙の「終焉」は確定した出来事ではなく、未来予測の一つとして表示しています。

初版の年代データは学習・探索用の概数です。日本の時代区分や生命誕生の時期には複数の説があります。
